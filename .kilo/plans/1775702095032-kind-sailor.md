# Plan para Resolver Ubicación del Conductor No Visible para Pasajero

## Problema Identificado
El pasajero ve el mapa, pero no ve la posición del conductor y aparece "Ubicación del conductor no disponible". Esto indica que `_driverPosition` es null, es decir, no hay datos en 'driverLocation' de Firestore para la ruta.

## Análisis
- El conductor comparte ubicación al iniciar ruta (LocationService.startSharingLocation), que actualiza Firestore cada cambio de posición.
- Los pasajeros escuchan 'driverLocation' via subscription en MapaTrayectoScreen.
- Causas posibles: Conductor no inició ruta, permisos GPS fallan, stream no emite, ruta no 'En curso', o timeInterval/distanceFilter no configurado para tiempo real.

## Solución Propuesta
1. **Asegurar compartir al iniciar ruta:**
   - En RouteCard._handleStartRoute, agregar `LocationService().startSharingLocation(widget.route.id)` después de startRoute.
   - En _handleFinalize, agregar `LocationService().stopSharingLocation(widget.route.id)` antes de finalizeRoute.

2. **Mejorar frecuencia de updates:**
   - Agregar `timeInterval: 5000` en LocationSettings de LocationService y MapaTrayectoScreen para updates cada 5s (según prompt).

3. **Cambiar mensaje informativo:**
   - En MapaTrayectoScreen._centerOnDriver, cambiar mensaje a "El conductor aún no ha iniciado la ruta" si _driverPosition == null.

4. **Quitar sharing duplicado:**
   - Remover `startSharingLocation` de MapaTrayectoScreen._initializeMap para conductor, ya que se hace al iniciar ruta.

## Implementación
- Archivos: `lib/widgets/route_card.dart`, `lib/services/location_service.dart`, `lib/screens/mapa_trayecto_screen.dart`
- Cambios: Agregar llamadas a start/stop sharing, timeInterval, mensaje mejorado.

## Riesgos
- Battery drain con updates cada 5s; usar solo mientras ruta activa.
- Si permisos fallan, conductor no comparte; mostrar error al iniciar.
