# Plan de Implementación del Módulo de Bazar para UniConnect UCEVA

## Descripción General
Implementar el módulo de bazar según los criterios de aceptación proporcionados. El módulo permitirá a estudiantes y docentes publicar productos académicos (libros, batas, calculadoras, etc.) con fotos y precio para venta o intercambio dentro de la comunidad UCEVA.

## Criterios de Aceptación
- Usuarios autenticados pueden acceder al formulario de publicar producto con campos: título, descripción (opcional), precio, categoría (libros, batas, calculadoras, equipos, otro), hasta 3 fotos.
- Campos obligatorios: título, precio, categoría, al menos 1 foto.
- Validación de campos faltantes con mensajes de error.
- Productos publicados aparecen en el listado del Bazar con estado 'Disponible'.
- Pantalla 'Mis publicaciones' muestra productos del usuario con opciones de editar y eliminar.

## Actualización: Nuevo Enfoque para Solución al Overflow en Mis Publicaciones

### Problema Identificado
El uso de `GridView` con `SliverGridDelegateWithFixedCrossAxisCount` y `childAspectRatio` restringe la altura de cada tarjeta, causando overflow cuando el contenido interno (imagen, texto, botones) excede el espacio asignado. Los ajustes previos (aumento de `aspectRatio`, reducción de tamaños) no resolvieron completamente el issue, persistiendo el "BOTTOM OVERFLOWED".

### Solución Propuesta
Cambiar de `GridView` a `ListView` para mostrar las publicaciones en una lista vertical de tarjetas de ancho completo. Esto elimina las restricciones de altura fija del grid y permite que cada tarjeta tenga altura variable sin causar overflow, ya que `ListView` maneja el scroll naturalmente.

- Ventajas: Más espacio para detalles, mejor UX para gestión (editar/eliminar), evita problemas de layout.
- Desventajas: Menos productos visibles a la vez, pero adecuado para pantalla de gestión personal.

### Cambios Requeridos
1. En `lib/screens/mis_publicaciones_screen.dart`:
   - Reemplazar `GridView.builder` con `ListView.builder`.
   - Actualizar `_ProductCard` para ocupar ancho completo (remover constraints de grid, ajustar diseño si necesario).
   - Mantener el `itemBuilder` similar, pero adaptar el layout de la tarjeta para lista vertical.

2. Ajustes en `_ProductCard`:
   - Cambiar de layout cuadrado a rectangular horizontal (imagen a la izquierda, detalles a la derecha).
   - Ejemplo: Row con imagen (altura fija) y Column con texto y botones.

### Verificación
- Probar con múltiples productos para asegurar scroll suave sin overflow.
- Comparar con `BazarScreen` (grid) para consistencia visual donde sea posible.
